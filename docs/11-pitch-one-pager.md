# Relicwake — one-pager

**Wake the Spire.** Idle auto-battle RPG para web, Android e iPhone.

Vaelith dorme. O tempo vira Wake. Você é um Waker: sobe o pico, acorda Relíquias e deixa o time lutar sozinho. Quando volta, o mundo rendeu. A próxima formação é sua.

| | |
| --- | --- |
| Gênero | Idle · gacha · auto-battle · online |
| Sessão | 3 min de check-in · 15 min de daily |
| Assinatura | 3 diretivas de batalha · baú diegético · guilda-fortaleza |
| Roster 1.0 | 28 heróis · 4+2 facções |
| Plataformas | PWA + Play + App Store, uma conta |
| Idiomas | PT-BR, EN |
| Modelo | F2P ético (odds, pity duro, compra direta, sem trade) |

**Não é** Naruto, não é clone de AFK, não é idle de planilha.

Público: quem joga AFK Arena / Journey / Pride of Nindo e quer o mesmo *contrato de tempo* num cliente web-native, com IP próprio.

Status: pré-produção. Ver `docs/README.md`.
